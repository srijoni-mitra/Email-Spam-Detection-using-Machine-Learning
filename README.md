📲**Email Spam Detection using Machine Learning**

A Machine Learning-based Email Spam Detection system developed using Python to classify emails as Spam or Ham (Not Spam). This project uses Natural Language Processing (NLP) techniques and Logistic Regression for accurate text classification.

## Features

✅ Email Classification (Spam/Ham)
✅ Text Preprocessing
✅ TF-IDF Vectorization
✅ Logistic Regression Model
✅ High Accuracy Prediction
✅ Real-time Custom Email Prediction

## Technologies Used

1. Python
2. Pandas
3. NumPy
4. Scikit-learn
5. Jupyter Notebook

## Machine Learning Concepts Used

* Train-Test Split
* TF-IDF Vectorization
* Logistic Regression
* Accuracy Evaluation

## Workflow

1. Data Collection
2. Data Preprocessing
3. Feature Extraction using TF-IDF
4. Model Training
5. Model Evaluation
6. Spam/Ham Prediction

## Project Outcome

Successfully built an Email Spam Detection model capable of predicting whether an email is Spam or Ham with high accuracy using Machine Learning techniques.
